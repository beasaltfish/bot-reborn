the workbench

Four stations, one bench.

Each station works on its own, so you can start wherever your idea is.

01

Simulate

Start from your idea. Pick parts and wire an ESP32 in the browser. No hardware needed.

02

Build

Flash firmware and set up Wi-Fi from a web page.

03

Configure

Pick a body, a play mode and a persona in Studio.

04

Run

A brain on your machine hears, thinks and drives the parts.

$ git clone https://github.com/beasaltfish/bot-reborn
$ npm install
$ server/models/fetch.sh
$ npm start
the first gadget

It started with a $4 toy robot.

No head, no brain, a line-following toy. An old phone became its face, a computer became its brain, and it started talking back. Everything that made that possible is now a workbench you can use for your own idea.

why it's different

Built to stay in your house.

Local-first

Speech, chat and keys stay on your computer. No account, no cloud brain required.

Any body, any trick

Phone or ESP32, screen or wand or motors. Swap a play mode — fortune telling, companion, voice control — and it's a new toy.

Open source

Every wire, every line of firmware, every prompt is in the repo. Bring your own parts.

If a talking toy sounds fun, give it a star.

It tells us to keep building, and it helps other makers find the bench.
