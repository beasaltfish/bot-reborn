工作台

四站，一张工作台。

每一站都能单独用，想法停在哪一步，就从哪一步开始。

01

模拟

从你的想法开始。选配件，在浏览器里给 ESP32 接线，不需要任何硬件。

02

搭建

在网页里烧录固件、设置 Wi-Fi。

03

配置

在 Studio 里选身体、玩法和人设。

04

运行

你电脑上的大脑听、想，并驱动各个外设。

$ git clone https://github.com/beasaltfish/bot-reborn
$ npm install
$ server/models/fetch.sh
$ npm start
第一个小玩意

一切从一个 30 块钱的玩具机器人开始。

没有头，没有脑子，只会巡线。一台旧手机成了它的脸，一台电脑成了它的大脑，它开始顶嘴了。让这件事成真的一切，现在是一张你可以拿来做自己想法的工作台。

有什么不同

为留在你家里而造。

本地优先

语音、对话和密钥都留在你的电脑上。不需要账号，也不需要云端大脑。

任意身体，任意玩法

手机或 ESP32，屏幕、签棒或电机。换一个玩法，比如占卜、陪伴、语音控制，就是一个新玩具。

开源

每一根线、每一行固件、每一段提示词都在仓库里。带上你自己的零件就行。

觉得会说话的玩具有意思，就点个星吧。

它让我们知道该继续做下去，也帮更多创客找到这张工作台。
