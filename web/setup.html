Connectivity tests

Every one of these tests the hardest case on purpose — see spec §9.3.

  1. Reads three fixed clips — fixtures/zh.wav, fixtures/en.wav and fixtures/mixed.wav: Chinese, English, and the two mixed inside one sentence. All three must come back with a transcript. When a file is missing you get fixtures/README.md's recording instructions rather than a silent skip.

  2. It has to answer and to call a tool. Those are two different things, verified separately.

  3. Synthesises 「『往前走』的英文是 go forward」. Both languages have to be intelligible.

  4. 200 ms forward; the car twitches.
